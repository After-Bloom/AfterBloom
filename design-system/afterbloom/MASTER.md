# AfterBloom Design System (MASTER)

Source of truth for all UI. Page-specific overrides live in `pages/<page>.md`.
Generated with the ui-ux-pro-max skill, then deliberately adjusted (see "Deviations").

## Direction
"A warm hand on the shoulder, not a hospital portal."
Soft, rounded, generous whitespace, mobile-first (390px), one signature element: the **bloom**,
a flower that opens as she completes check-ins. Style family: *Nature Distilled + Soft UI*
(warm cream surfaces, blush and rose, sage for growth, soft layered shadows, no hard lines).
Dials: variance 3 (calm, centred), motion 4 (standard, meaningful), density 3 (spacious).

## Deviations from the raw skill output (and why)
| Skill output | Used instead | Reason |
|---|---|---|
| Cyan `#0891B2` "Minimalism & Swiss" | Rose + cream + sage | Cyan/Swiss reads clinical; brief asks for warmth |
| Atkinson Hyperlegible | Cormorant Garamond (headings), Nunito (body), Noto Sans/Serif Devanagari (Hindi) | Atkinson has no Devanagari glyphs; Hindi is a core requirement |
| Primary `#C85D68` (old app) | `#B04A56` | `#C85D68` with white text is 4.0:1; `#B04A56` is 5.3:1 (WCAG AA) |

Triage levels always pair colour with an icon and a word (never colour alone).

## Typography
- Headings: Cormorant Garamond 500-700 (Latin), Noto Serif Devanagari (Hindi fallback)
- Body/UI: Nunito 400-800 (Latin), Noto Sans Devanagari (Hindi fallback)
- Scale: 12 / 14 / 16 / 18 / 24 / 32 / 44. Body 16px, line-height 1.6 (Hindi 1.7).
- Hindi strings are longer: never fixed-width labels, allow wrapping, `min-w-0` on flex text.

## Spacing, radius, elevation
- 4/8 spacing scale; section rhythm 16 / 24 / 32 / 48.
- Radius: control 16px, card 24px, pill 9999px, sheet 28px top corners.
- Elevation: `shadow-soft` (cards), `shadow-lift` (hover/raised), `shadow-sheet` (bottom sheets).
- Touch targets >= 44x44px, >= 8px between targets. Bottom nav height 64px + safe-area inset.
- Layout: single column max 480px feel on phones; laptop layouts (professional dashboard)
  use a sidebar and a 12-col grid, container max 1200px.

## Motion (Motion library, `motion/react`, LazyMotion `m.*`)
All values live in `lib/motion.ts`. One spring set, reused everywhere:
- `gentle` (default for entrances, page transitions), `snappy` (taps, toggles), `soft`
  (bloom, breathing), plus ease `[0.22, 1, 0.36, 1]` for opacity/colour.
- CSS equivalents generated by Motion's `spring()` are in `globals.css` as
  `--spring-gentle`, `--spring-snappy`, `--spring-soft` for pure-CSS transitions.
- Animate `transform` and `opacity` only. Exit faster than enter (~65%). Stagger 40ms.
- `prefers-reduced-motion`: `MotionConfig reducedMotion="user"` (transforms off, opacity stays)
  plus a CSS fallback. The idle/parallax/petal loops are disabled entirely.
- **Crisis screen: no motion beyond a plain fade. It renders from local state, no loading state.**

## Safety rules that override style
Crisis screen instant and ungated; Tele-MANAS 14416 / 1-800-891-4416 and 112 only (no KIRAN);
no score/grade for the mother; EPDS results per spec (>=13 shows only "Our care team will be in
touch" + Tele-MANAS, never the word "depression"); Q10 >= 1 opens the crisis screen;
Tele-MANAS visible beside every paid/booking option; professionals labelled "Sample profile";
quick-exit on every screen; AI never writes advice (prewritten templates only).

## Components checklist
Icons: Lucide, stroke 1.75, one style (no emoji as structural icons; emoji faces are allowed
only as the mood scale input, always with a text label). Focus ring: 3px `primary` at 40%
plus 2px offset, always visible. Every control has a label (`aria-label` for icon-only).
Dark mode designed alongside light (class strategy, `ab.theme` in localStorage, no flash).

## Anti-patterns
Cold clinical blues, neon, purple/pink AI gradients, wellbeing scores, red-only meaning,
hover-only affordances, motion on the crisis screen, fixed-width Hindi labels.

## Landing page (route `/`) notes
- Own header (no app chrome). `Need help now?` is a plain `<a href="/crisis">`, always visible, works without JS.
- Illustration: `components/landing/Illustration.tsx`, layered groups `#bg-shapes #petals #figure(#mother #baby #dupatta) #flower`, inline SVG only.
- Scroll story (hero + "why") drives a sticky illustration (shrink, move) and a `Bloom` whose `--b` CSS variable opens it.
- Idle loops are CSS keyframes, paused (`data-playing=false`) when the story is off-screen or the tab hidden. Reduced motion: no loops, no petals, no parallax, static art, open flower.
- Handoff: a bloom-coloured circle grows from the pressed button, then routes to `/home` (mother) or `/pro`.
- Mother's home moved from `/` to `/home`.
